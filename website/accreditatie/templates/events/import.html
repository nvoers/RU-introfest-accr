How it works

  • First row must be a header. Comma, semicolon and tab separated files all work (Excel exports are fine).
  • type is one of Artist, Crew, Guest, Press or Supplier (defaults to Crew).
  • access_level and entrance must match names from Setup.
  • Every row is added as a new accreditation — importing the same file twice creates duplicates.
  • An exported CSV can be imported into another event.
